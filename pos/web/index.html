Become a validator.
Run a synced node, keep its consensus key private, then register its public key and self-delegate LAC. Admission to the active set follows bonded stake and the 32-validator limit, with no wallet invitation list.
1. Start your node
  1. Download the verified node kit and follow its Linux instructions.
  2. Wait until the node reports that it is synced.
  3. Copy only the consensus public key into the registration form.
Node setup instructions →
Never run two validators with the same consensus key. A node must remain online to sign blocks. Bootstrapping validators currently share one host.
2. Register your validator
This form sets 5% commission, a 20% maximum, and a maximum increase of 1 percentage point per day. Minimum self-delegation: 10 LAC.
